# Спецификация агента для «Годвилля»

## Статус

Комплект описывает требования к автономному агенту. Целевой runtime — Node.js/TypeScript, SQLite и Docker. По умолчанию должен запускаться `dry-run`: агент наблюдает, планирует и журналирует намерения, но не нажимает элементы интерфейса. Браузерный адаптер включается отдельной явной настройкой владельца.

Автоматическое управление конфликтует с опубликованными правилами Godville. Этот факт фиксируется как риск эксплуатации и не заменяется обещанием отсутствия санкций. Проект не предусматривает обход обнаружения и не заявляет «невидимость» автоматизации.

Дата подготовки и проверки источников: **20 сентября 2026 года**.

## Принципы

- Игровые факты берутся из курируемого каталога знаний с URL источника, датой проверки и версией записи; приоритет имеют официальные публикации, затем Энциклобогия.
- Оперативное состояние подтверждается актуальным наблюдением UI; устаревшие либо несовместимые данные блокируют зависимое действие.
- Операции, наблюдения и знания сохраняются раздельно в SQLite и связываются идентификаторами решения.
- Обработчики кнопок версионируются и выбирают элемент по точной роли и тексту, проверяя предусловие до клика и постусловие после него.
- Задержки реакции и небольшой ограниченный сдвиг/дрожание точки клика настраиваются только как вариативность исполнения и тестирования интерфейса. Они не предназначены для обхода обнаружения.
- Система не обещает победы, сроки прогресса, непрерывную автономность или отсутствие санкций.
